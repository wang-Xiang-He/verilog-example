## ① UART 收發器（100 分）

**配分**：鮑率產生器 20 + 發送器 40 + 接收器 40

```
   閒置  起始   d0  d1 ... d7   停止  閒置
   ▔▔▔▔╲___╱▔╲__╱▔ ... ▔╲___╱▔▔▔▔▔
```

**三個部分：**
- `baud_gen` — 每 N 拍產生一個**一拍寬**的 tick
- `uart_tx` — 四態狀態機 + PISO 移位暫存器
- `uart_rx` — ★ 最難，要自己找起始邊緣並**對齊到位元中央**取樣

**測試方式**：把發送器的輸出直接接到接收器的輸入做**迴路測試**。

**最容易錯的地方：**
1. LSB first —— 先送 `data[0]`，不是 `data[7]`
2. `tx` 一定要**上正反器**，用 `assign` 會有毛刺
3. `tick` 只能高**一拍**，高兩拍會讓 UART 快一倍
4. 接收要等 **1.5 個位元時間**才開始取樣（半個位元對齊中央 + 一個位元到 d0）

> **做完等於你有一個真正能用的 UART IP** —— 第 15 週的
> `05_uart_tx` 只有發送，這題是完整版。

## ② 簡易 8-bit CPU（100 分）

**配分**：LDA 20 + ADD 25 + STA 25 + JMP 20 + 綜合程式 10

```
   ┌──────────────┐  控制訊號  ┌────────────────────┐
   │  控制器 FSM   │──────────→│  資料路徑           │
   │ FETCH/DECODE │←──────────│  PC / ACC / 記憶體  │
   │   /EXECUTE   │  指令      └────────────────────┘
   └──────────────┘
```

**★ 這就是第 10 週 `02_datapath` 的架構放大版。**

**指令格式**（8 位元）：`[7:6] opcode | [5:0] addr`

| opcode | 助記符 | 動作 |
|:---:|---|---|
| `00` | `LDA addr` | `ACC ← MEM[addr]` |
| `01` | `ADD addr` | `ACC ← ACC + MEM[addr]` |
| `10` | `STA addr` | `MEM[addr] ← ACC` |
| `11` | `JMP addr` | `PC ← addr` |

**最容易錯的地方：**
> ⚠️ **`FETCH` 階段已經把 `pc` 加過 1 了**，
> `JMP` 在 `EXECUTE` 要**直接覆蓋**成 `addr`，不是再加。
>
> 測試 4 就是專門抓這個：跳對 `ACC=101`，沒跳 `ACC=201`。

**程式怎麼結束**：偵測「`JMP` 跳到自己這一行」→ `halted` 拉高。

> **做完等於你做出一台真的 CPU。**
> 它有取指令、解碼、執行三個階段，有 PC、ACC、IR，會算術也會跳躍。
> Intel 4004（1971 年第一顆商用 CPU）也就是這個架構再複雜一點而已。

## ③ VGA 訊號產生器（100 分）

**配分**：水平時序 30 + 垂直時序 30 + video_on 20 + 棋盤格圖樣 20

**規格**：640×480 @ 60Hz，像素時脈 25.175 MHz

```
   |<---- 640 可見 ---->|<-16->|<--96-->|<-48->|   = 800
   ┌────────────────────┐      ┌────────┐
   │      畫面內容       │      │        │
   └────────────────────┘──────┘        └──────
                          前緣   同步脈衝  後緣

   垂直：480 + 10 + 2 + 33 = 525 條掃描線
```

**★ 為什麼有看不到的區域？**
VGA 是為映像管螢幕設計的 —— 電子槍掃完一行要花時間**飛回**左邊，
那段時間不能有畫面。液晶螢幕早就不需要了，但規格沿用至今。

**最容易錯的地方：**
1. ⚠️ `hsync`/`vsync` 在這個模式是**低準位有效**（同步期間輸出 0）
2. ⚠️ `v_cnt` **只能在 `h_cnt` 歸零時才動**，不是每拍都動
3. ⚠️ 消隱期間 `rgb` 一定要是 `000` —— 送顏色會讓螢幕認不出訊號
4. 邊界用 `<` 還是 `<=`，差一格整張畫面就歪掉

> 測試平台會數「一張畫面裡 `video_on` 為 1 的像素數」，
> 正確答案剛好是 640 × 480 = **307,200**。

**★ 加分挑戰**：棋盤格用了除法（`px / 80`），第 11 週學過除法很貴。
解答檔裡附了一個**完全不用除法**的版本（`vga_pattern_nodiv`），
用兩個「每 80 個翻一次」的旗標直接 XOR。看得懂再自己寫一次。
