# 17_BCDadder4 範例說明：四位元 BCD 加法器（範例練習 5-005）

## 1. 背景知識：什麼是 BCD？

### 1.1 普通二進位 vs BCD

我們平常用的二進位，4 個位元可以表示 0~15 共 16 種數字。
但 **BCD**（Binary-Coded Decimal，二進位編碼十進位）規定：

> **每 4 個位元只表示 0~9，對應一個十進位數字。10~15（1010~1111）是不合法的。**

| 十進位 | 普通二進位 | BCD 編碼 |
|--------|-----------|----------|
| 0 | 0000 | 0000 |
| 1 | 0001 | 0001 |
| ... | ... | ... |
| 9 | 1001 | 1001 |
| 10 | **1010** | ❌ 不合法！要用 **0001 0000**（兩組 4-bit） |
| 15 | **1111** | ❌ 不合法！要用 **0001 0101** |

**簡單說：BCD 就像每個十進位數字各自用 4-bit 來編碼，類似人類的十進位思維。**

### 1.2 BCD 的用途

七段顯示器、計算機、數位時鐘等需要「直接顯示十進位數字」的場合，用 BCD 最方便，不需要做二進位→十進位的轉換。

## 2. 這個範例在做什麼？

這個範例實作 **1 位數的 BCD 加法器**：輸入兩個 BCD 數字（各 4 位元，0~9）加上進位 Cin，輸出 BCD 結果。

### 2.1 問題：為什麼不能直接用二進位加法？

普通二進位加法器在加到 15 才進位，但 BCD 加到 **9 就要進位**。

**具體例子：5 + 7 = 12**

```
直接二進位加法：
    0101  (5)
  + 0111  (7)
  --------
    1100  (12)    ← 二進位結果是 1100
```

但 1100 = 十進位 12，4-bit 裝得下不會進位。
而 BCD 的正確答案應該是：**Cout=1, S=0010**（十進位 "12" = 進位1 + 個位2）

1100 在 BCD 裡是**不合法的**（> 9），所以需要「修正」。

### 2.2 解法：結果 > 9 時，加 6 修正

為什麼加 **6**？因為 BCD 跳過了 10~15 這 **6 個**不合法的碼：

```
十進位:  0  1  2 ... 9  10  11  12  13  14  15  16
BCD碼:   0  1  2 ... 9  ←── 這 6 個不合法 ──→  進位！
二進位:  0  1  2 ... 9  10  11  12  13  14  15  16
```

所以二進位結果 > 9 時，加上 6 就能「跳過」這 6 個不合法碼，得到正確的 BCD 結果。

### 2.3 完整手算範例

#### 範例 A：3 + 4 = 7（不需修正）

```
步驟 1：二進位加法
    0011  (3)
  + 0100  (4)
  --------
  0_0111  →  C4=0, S_tmp=0111 (7)

步驟 2：判斷需不需要修正
    7 ≤ 9，不需要修正（F=0）

步驟 3：加 0（不修正）
    0111 + 0000 = 0111

最終結果：Cout=0, S=0111  →  十進位 "07" ✓
```

#### 範例 B：5 + 5 = 10（需要修正，S_tmp > 9）

```
步驟 1：二進位加法
    0101  (5)
  + 0101  (5)
  --------
  0_1010  →  C4=0, S_tmp=1010 (10)

步驟 2：判斷需不需要修正
    10 > 9，需要修正！（F=1）
    （S_tmp = 1010，S3=1 且 S1=1 → F=1）

步驟 3：加 6 修正
    1010  (S_tmp)
  + 0110  (6)
  --------
  1_0000  →  進位=1, 結果=0000

最終結果：Cout=1, S=0000  →  十進位 "10" ✓
```

#### 範例 C：9 + 8 = 17（需要修正，C4=1）

```
步驟 1：二進位加法
    1001  (9)
  + 1000  (8)
  --------
  1_0001  →  C4=1, S_tmp=0001 (17，但 S_tmp 只有低4位 = 1)

步驟 2：判斷需不需要修正
    C4=1，已經溢出了，一定需要修正！（F=1）

步驟 3：加 6 修正
    0001  (S_tmp)
  + 0110  (6)
  --------
  0_0111  →  結果=0111

最終結果：Cout=1, S=0111  →  十進位 "17" ✓
```

#### 範例 D：9 + 9 + 1 = 19（最大值）

```
步驟 1：二進位加法
    1001  (9)
  + 1001  (9)
  +    1  (Cin)
  --------
  1_0011  →  C4=1, S_tmp=0011 (19，S_tmp 低4位 = 3)

步驟 2：C4=1 → F=1，需要修正

步驟 3：加 6 修正
    0011 + 0110 = 1001

最終結果：Cout=1, S=1001  →  十進位 "19" ✓
（9 + 9 + 1 = 19 是 1 位 BCD 加法器能產生的最大值）
```

## 3. 修正條件 F 的推導

二進位加法結果 {C4, S3, S2, S1, S0} 的範圍是 0~19（因為最大 9+9+1=19）。

我們需要找出 **哪些值 > 9**，列出真值表：

| 二進位結果 | C4 | S3 | S2 | S1 | S0 | > 9? | 觸發原因 |
|-----------|----|----|----|----|-----|------|---------|
| 0~9 | 0 | 0/1 | x | x | x | ❌ |  |
| 10 = 0_**1010** | 0 | **1** | 0 | **1** | 0 | ✅ | S3·S1 |
| 11 = 0_**1011** | 0 | **1** | 0 | **1** | 1 | ✅ | S3·S1 |
| 12 = 0_**1100** | 0 | **1** | **1** | 0 | 0 | ✅ | S3·S2 |
| 13 = 0_**1101** | 0 | **1** | **1** | 0 | 1 | ✅ | S3·S2 |
| 14 = 0_**1110** | 0 | **1** | **1** | **1** | 0 | ✅ | S3·S2（或S3·S1）|
| 15 = 0_**1111** | 0 | **1** | **1** | **1** | 1 | ✅ | S3·S2（或S3·S1）|
| 16 = **1**_0000 | **1** | 0 | 0 | 0 | 0 | ✅ | C4 |
| 17 = **1**_0001 | **1** | 0 | 0 | 0 | 1 | ✅ | C4 |
| 18 = **1**_0010 | **1** | 0 | 0 | 1 | 0 | ✅ | C4 |
| 19 = **1**_0011 | **1** | 0 | 0 | 1 | 1 | ✅ | C4 |

歸納出三種觸發修正的情形：

1. **C4 = 1**（結果 ≥ 16）
2. **S3 = 1 且 S2 = 1**（結果 12~15）
3. **S3 = 1 且 S1 = 1**（結果 10、11、14、15）

合併成一個布林公式：

```
F = C4 + S3·S2 + S3·S1
  = C4 + S3·(S2 + S1)      ← 提出 S3
```

**F = 1 就代表「需要修正（加 6）」，同時 F 也就是十進位的進位輸出 Cout。**

## 4. 電路架構（方塊圖詳解）

整個電路分**兩級**，都是用同一個 `adder4` 模組：

```
        輸入
        ┃
   A[3:0]  B[3:0]  Cin
     ┃       ┃      ┃
 ════╋═══════╋══════╋════════════════════════════════
 第  ┃       ┃      ┃
 一  ┌───────▼──────▼──┐
 級  │    adder4        │   ← 實例名稱：BINADD（Binary Add，二進位加法）
     │  {Cout,S}=A+B+Cin│
     └──┬───────────┬──┘
        │           │
       C4      S_tmp[3:0]     ← 這是「還沒修正」的二進位結果
        │           │
 ════════╋═══════════╋═══════════════════════════════
 修      │           │
 正  ┌───▼───────────▼───┐
 判  │ F = C4 | S3&(S2|S1)│    ← F=1 代表需要修正
 斷  └───┬───────────────┘
         │ F
         ├───────────────────────► Cout（十進位進位）
         │
         ▼
     B_mod = {0, F, F, 0}        ← F=1 → 0110(6)；F=0 → 0000(0)
         │
 ════════╋═══════════════════════════════════════════
 第      │       S_tmp
 二  ┌───▼───────────▼──┐
 級  │    adder4         │  ← 實例名稱：MODADD（Modify Add，修正加法）
     │  S = S_tmp + B_mod│
     │  Cin = 0          │
     └──┬───────────────┘
        │（Cout 不接，不需要）
        │
       S[3:0]                    ← 最終 BCD 結果
```

## 5. 逐行程式碼解說

### 5.1 adder4.v — 4 位元二進位加法器

```verilog
module adder4 (
    input  [3:0] A,       // 加數 A（4 位元）
    input  [3:0] B,       // 加數 B（4 位元）
    input        Cin,     // 進位輸入（1 位元）
    output [3:0] S,       // 和（4 位元）
    output       Cout     // 進位輸出（1 位元）
);
    assign {Cout, S} = A + B + Cin;
    //     ──────────
    //     把 5 位元結果拆成：
    //       最高位 → Cout（進位）
    //       低 4 位 → S（和）
endmodule
```

這是一個**純組合邏輯**的加法器，用 `assign` 連續指派，不需要 `always` 或 `reg`。

### 5.2 BCDadder4.v — BCD 加法器主體

```verilog
module BCDadder4 (
    output [3:0] S,        // BCD 結果（修正後的和）
    output       Cout,     // 十進位進位
    input        Cin,      // 進位輸入
    input  [3:0] A,        // BCD 數字 A（0~9）
    input  [3:0] B         // BCD 數字 B（0~9）
);
```

#### 內部訊號宣告

```verilog
    wire [3:0] S_tmp;      // 第一級加法器的和（還沒修正）
    wire       C4;         // 第一級加法器的進位
    reg  [3:0] B_mod;      // 修正值：0110 或 0000
    reg        F;          // 修正旗標：1=需要加6
```

> **為什麼 `S_tmp` 和 `C4` 是 `wire`，`B_mod` 和 `F` 是 `reg`？**
> - `S_tmp`、`C4` 是由 adder4 模組的**輸出埠驅動**的，所以用 `wire`
> - `B_mod`、`F` 在 `always` 區塊裡被賦值，所以**必須用 `reg`**

#### 第一級：二進位加法

```verilog
    adder4 BINADD (.A(A), .B(B), .Cin(Cin), .S(S_tmp), .Cout(C4));
```

把 A + B + Cin 的結果存到 `{C4, S_tmp}`。這是**還沒修正**的二進位結果。

> **語法說明：這是「模組實例化」**
> - `adder4` = 模組名稱
> - `BINADD` = 實例名稱（你可以取任何名字，方便辨識）
> - `.A(A)` = 把外部的 `A` 接到 adder4 的埠 `A`

#### 修正判斷

```verilog
    always @(*) begin
        F     = C4 | (S_tmp[3] & (S_tmp[2] | S_tmp[1]));
        B_mod = {1'b0, F, F, 1'b0};
    end
```

逐行解讀：

| 程式碼 | 意義 |
|--------|------|
| `C4` | 二進位加法進位=1 → 結果≥16，一定要修正 |
| `S_tmp[3] & (S_tmp[2] \| S_tmp[1])` | S3=1 且 (S2=1 或 S1=1) → 結果在 10~15，也要修正 |
| `F = ...` | 上面兩個條件用 OR 合併 |
| `{1'b0, F, F, 1'b0}` | **連結運算子**，組出 4 位元的修正值 |

`{1'b0, F, F, 1'b0}` 的巧妙之處：

```
F=0 → {0, 0, 0, 0} = 0000 (十進位 0)  → 不修正
F=1 → {0, 1, 1, 0} = 0110 (十進位 6)  → 加 6 修正
```

不需要用 `if-else`，一行就搞定！

#### 第二級：修正加法

```verilog
    adder4 MODADD (.A(S_tmp), .B(B_mod), .Cin(1'b0), .S(S), .Cout());
```

| 接線 | 說明 |
|------|------|
| `.A(S_tmp)` | 第一級的結果 |
| `.B(B_mod)` | 修正值（0 或 6） |
| `.Cin(1'b0)` | 進位固定接 0（不需要額外進位） |
| `.S(S)` | 輸出修正後的 BCD 結果 |
| `.Cout()` | **括號裡留空 = 不接**。第二級不會產生需要用到的進位 |

#### 進位輸出

```verilog
    assign Cout = F;
```

F=1 代表結果 > 9，也就是十進位要進位。所以 F 直接就是 Cout。

### 5.3 BCDadder4_tb.v — 測試平台

```verilog
BCDadder4 uut (.S(S), .Cout(Cout), .Cin(Cin), .A(A), .B(B));
```

- `uut` = Unit Under Test（被測試的單元），是 BCDadder4 的實例名稱

#### 代表性測試（5 筆）

```verilog
A = 4'd3; B = 4'd4; Cin = 0; show;   // 3+4 = 7，不修正
A = 4'd5; B = 4'd5; Cin = 0; show;   // 5+5 = 10，S3·S1 觸發
A = 4'd7; B = 4'd6; Cin = 0; show;   // 7+6 = 13，S3·S2 觸發
A = 4'd9; B = 4'd8; Cin = 0; show;   // 9+8 = 17，C4 觸發
A = 4'd9; B = 4'd9; Cin = 1; show;   // 9+9+1 = 19，最大值
```

#### 自動全面檢查（200 筆）

```verilog
for (k = 0; k < 2; k = k + 1)           // Cin = 0, 1
    for (i = 0; i < 10; i = i + 1)       // A = 0~9
        for (j = 0; j < 10; j = j + 1)   // B = 0~9
```

檢查方式：

```verilog
exp_sum = i + j + k;                     // 用整數算出期望的十進位結果
if (Cout * 10 + S != exp_sum)            // 比對電路輸出
    errors = errors + 1;                 // Cout=1 代表十位是1，乘以 10 再加個位
```

#### 階層式名稱存取內部訊號

```verilog
$display("... F=%b ...", uut.F);
$display("... C4=%b ...", uut.C4);
$display("... S_tmp=%b ...", uut.S_tmp);
```

testbench 可以用 `uut.訊號名` 直接讀取 BCDadder4 內部的訊號，這在 debug 時非常有用。
（正式設計中模組內部是封裝的，但在模擬時可以這樣「偷看」。）

## 7. 重點整理

| 觀念 | 說明 |
|------|------|
| BCD | 4 位元表示 0~9，超過 9 不合法 |
| 為什麼加 6 | 跳過 10~15 這 6 個不合法的碼 |
| 修正條件 | 二進位和 > 9 → F = C4 + S3·(S2 + S1) |
| 修正方法 | F=1 時加 6（0110），F=0 時加 0（不變） |
| `{0, F, F, 0}` | 連結運算子巧妙組出 0 或 6，不需要 if-else |
| 階層式設計 | 同一個 `adder4` 模組實例化兩次（BINADD、MODADD） |
| `.Cout()` | 埠留空 = 不接，表示這個輸出不需要 |
| `uut.F` | testbench 用階層式名稱讀取模組內部訊號 |
| `wire` vs `reg` | 被模組輸出驅動 → `wire`；在 `always` 中賦值 → `reg` |
