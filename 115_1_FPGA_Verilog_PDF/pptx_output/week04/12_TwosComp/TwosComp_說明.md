# 12_TwosComp 範例說明：8 位元 2 的補數（casex）

## 1. 這個範例在做什麼？

求 8 位元數的 **2 的補數**（也就是 `-In_Data`）。一般做法是「1 的補數再加 1」，講義用另一種不需要加法器的規則：

> 從最低位元往上找到**第一個 1**，這個 1 和它右邊的位元**保持不變**，左邊的位元**全部反相**。

```
In_Data = 1101_0010
                ↑ 第一個 1 在第 1 位
保持：          __10
反相：   0010_11
結果    = 0010_1110
```

「左邊全部反相」= XOR 一個遮罩（左邊都是 1、右邊都是 0）：`1101_0010 ^ 1111_1100 = 0010_1110`。

---

## 2. 檔案說明

### TwosComp.v
```verilog
casex (In_Data)
    8'b???????1 : Out_Data = In_Data ^ 8'hfe;  // 第一個 1 在第 0 位
    8'b??????10 : Out_Data = In_Data ^ 8'hfc;  // 第一個 1 在第 1 位
    8'b?????100 : Out_Data = In_Data ^ 8'hf8;
    ...
    8'b10000000 : Out_Data = In_Data ^ 8'h00;
    default     : Out_Data = In_Data;          // In_Data = 0
endcase
```
- `?` 是不在乎位元：`8'b??????10` 表示「最低兩位是 10，其他位不管」。
- 8 個項目互斥（第一個 1 的位置只有一個），所以可加 `// synopsys parallel_case`。
- 講義第 37 頁下方的註記：把 `?` 換成 `x` 時，`casex` 可以、`casez` 不行（casez 只認 z/?）；
  而一般的 `case` 會把 `?` 當成真的 z 去比對，永遠不符合，全部走 default。

### TwosComp_tb.v
先顯示講義上的例子，再把 0~255 全部跑一遍，和 `~In_Data + 1` 比對。

---

## 3. 預期輸出

```
In_Data=11010011  ->  Out_Data=00101101   (1's+1 = 00101101)
In_Data=11010010  ->  Out_Data=00101110   (1's+1 = 00101110)
In_Data=01010000  ->  Out_Data=10110000   (1's+1 = 10110000)
In_Data=10000000  ->  Out_Data=10000000   (1's+1 = 10000000)
In_Data=00000001  ->  Out_Data=11111111   (1's+1 = 11111111)
In_Data=00000000  ->  Out_Data=00000000   (1's+1 = 00000000)
check 0~255: errors = 0
```

### 觀察重點
- 前三行就是講義第 37 頁註解中的三組數字。
- `1000_0000`（−128）的 2 補數還是自己：8 位元有號數的範圍是 −128 ~ 127，+128 放不下。
- 自動檢查 256 種輸入 `errors = 0`，證明 casex 寫法和「1 的補數 + 1」完全相同。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 2 的補數 | = 1 的補數 + 1 = 負數的表示法 |
| XOR 遮罩 | `^ 1` 反相、`^ 0` 不變 |
| `casex` + `?` | 只比對指定位元 |
| 自動檢查 | for 迴圈跑遍所有輸入，比對參考答案 |
