# 16_Repeat_1s 範例說明：repeat 迴圈計算 1 的個數（範例練習 5-004）

## 1. 這個範例在做什麼？

計算 8 位元資料 `Din` 裡有**幾個位元是 1**（又叫 population count）。

講義第 48 頁的說明：讓迴圈執行 8 次，每次把 `tmpr` **右移一位**，並判斷它的最低位元 `tmpr[0]` 是否為 1，
以計數出現 1 的次數。

```
Din = 0101_0101
第 1 圈 tmpr = 0101_0101  tmpr[0]=1  Cout=1
第 2 圈 tmpr = 0010_1010  tmpr[0]=0  Cout=1
第 3 圈 tmpr = 0001_0101  tmpr[0]=1  Cout=2
...
第 8 圈結束          ones = 4
```

---

## 2. 檔案說明

### repeat_1s.v
```verilog
always @(*) begin
    Cout = 4'b0;
    tmpr = Din;
    repeat (length) begin
        if (tmpr[0])
            Cout = Cout + 4'b0001;
        tmpr = tmpr >> 1;
    end
    ones = Cout;
end
```
- `repeat (N)`：固定執行 N 次，不需要迴圈變數。
- `ones` 是 4 位元：最多 8 個 1，8 = `1000` 需要 4 位元。
- 這裡的 `=` 是**阻隔式**賦值，一行做完才做下一行，所以 `tmpr` 每圈都拿到右移後的新值。
  組合邏輯的計算步驟一定要用 `=`，換成 `<=` 結果就錯了。
- 和 for 一樣，合成時展開成 8 份「判斷 + 加法」的電路。

### repeat_1s_tb.v
講義第 49 頁的測試平台讓 `Din` 從 0 數到 255，輸出太長；
這裡改用講義第 48 頁模擬結果中的 9 筆資料，方便逐行對照。

## 3. 預期輸出

```
t=0   ones = 0,  Din = 00000000
t=10  ones = 4,  Din = 01010101
t=20  ones = 5,  Din = 11001101
t=30  ones = 1,  Din = 00000100
t=40  ones = 6,  Din = 11110101
t=50  ones = 5,  Din = 01100111
t=60  ones = 2,  Din = 10000010
t=70  ones = 4,  Din = 00111100
t=80  ones = 5,  Din = 10110101
```

### 觀察重點
- 每一行都和講義第 48 頁的 `#0 ones = 0, Din = 00000000 ...` 相同。
- 自己數數看：`1100_1101` 有 1+1+0+0+1+1+0+1 = 5 個 1。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `repeat (N)` | 固定重複 N 次 |
| 右移 `>>` | 每次把下一個位元移到最低位 |
| 阻隔式 `=` | 組合邏輯的逐步計算要用 `=` |
| 輸出寬度 | 最多 8 個 1 → 需要 4 位元 |
