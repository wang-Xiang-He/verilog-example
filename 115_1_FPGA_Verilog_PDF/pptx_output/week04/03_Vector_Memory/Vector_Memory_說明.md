# 03_Vector_Memory 範例說明：向量、陣列、記憶體、位元選取

## 1. 這個範例在做什麼？

只有 testbench，用 `$display` 示範講義第 9~12 頁的宣告與存取方式：

- **向量**（vector）：一個多位元的訊號，例如 32 位元的 `Result`。
- **陣列 / 記憶體**（array / memory）：很多個同樣寬度的元素，例如 1024 個 8 位元。
- **位元選取**（bit-select）`a[0]` 與**部分選取**（part-select）`a[7:4]`。

---

## 2. 語法重點

### 向量：`[MSB:LSB]` 寫在名稱**前面**
```verilog
reg  [31:0] Result;     // 1 個 32 位元的 reg
wire [15:0] bus;        // 1 個 16 位元的 wire
```
> ⚠ 講義第 9 頁寫成 `wire bus [15:0];`、`reg Result [31:0];`。
> `[15:0]` 寫在名稱**後面**是宣告**陣列**（16 個各自獨立的 1 位元元素），不是向量。
> ModelSim 雖然還是編譯得過，但陣列不能當成一個 16 位元的數字來用（例如寫 `bus + 1` 會出現 `Illegal operation on unpacked type` 錯誤），
> 這不是講義想表達的意思。本範例已改正為向量寫法。

### 記憶體：兩組中括號
```
reg [7:0]  Memory1Byte [1023:0];
    ─────              ─────────
    每個元素 8 位元     共 1024 個元素（位址 0~1023）
```

### 存取記憶體
```verilog
Memory1Byte[586] = Byte1;       // 寫入第 586 個元素
Byte2 = Memory1Byte[125];       // 讀出第 125 個元素（8 位元）
Bit2  = Byte2[4];               // 再取出第 4 位元
```
- Verilog-1995 **不能**寫 `Memory1Byte[125][4]`，要像講義一樣分兩步。
- Verilog-2001 起可以直接寫 `Memory1Byte[125][4]`（ModelSim 支援）。

### 位元選取 / 部分選取
```verilog
c[0]   = a[0] & b[0];           // 只算 1 個位元
c[7:0] = a[7:0] & b[7:0];       // 8 個位元一起算，等同 c = a & b
c[7:4] = 4'b0000;               // 只改高 4 位元
```

---

## 3. 預期輸出

```
(1) Result = 1234abcd
    bus  = Result[15:0] = abcd
    even = ~Result[0]   = 0   (Result[0] = 1)
(2) Memory1Bit[321] = 1  ->  Bit1 = 1
(3) Memory1Byte[586] = Byte1 = 10100101
(4) Byte2 = Memory1Byte[125] = 00010000  ->  Bit2 = Byte2[4] = 1
    Verilog-2001: Memory1Byte[125][4] = 1
(5) Memory1Byte[0] = xxxxxxxx  (never written)
(6) a=11001010 b=10100110
    c[0]   = a[0] & b[0]     -> c = 00000000
    c[7:0] = a[7:0] & b[7:0] -> c = 10000010
    c[7:4] = 4'b0000         -> c = 00000010
```

### 觀察重點
- (1) `bus` 只拿到 `Result` 的低 16 位元 `abcd`。
- (5) 沒寫入過的記憶體元素全部是 **x**；硬體上電時 RAM 的內容也是不確定的。
- (6) 最後一行：`c[7:4]` 被清成 0，低 4 位元 `0010` 保持不變。
- 在 Wave 視窗看不到記憶體內容時，可以用 **View > Memory List** 查看 `Memory1Byte`。

---

## 4. 重點整理

| 寫法 | 意義 |
|------|------|
| `reg [7:0] r;` | 1 個 8 位元向量 |
| `reg r [7:0];` | 8 個 1 位元元素的陣列 |
| `reg [7:0] m [0:1023];` | 1024 × 8 位元記憶體 |
| `a[3]` | 位元選取 |
| `a[7:4]` | 部分選取 |
| `[MSB:LSB]` | 左邊是最高位元（MSB），右邊是最低位元（LSB） |
