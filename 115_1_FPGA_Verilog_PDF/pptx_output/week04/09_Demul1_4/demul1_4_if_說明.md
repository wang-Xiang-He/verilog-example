# 09_Demul1_4 範例說明：1 對 4 解多工器（範例練習 5-001）

## 1. 這個範例在做什麼？

**解多工器**（Demultiplexer）和多工器相反：1 個輸入 `I`，依選擇線 `{S1, S0}` 送到 4 個輸出中的一個，其他輸出為 0。

| S1 S0 | y[3] | y[2] | y[1] | y[0] |
|-------|------|------|------|------|
| 0 0 | 0 | 0 | 0 | **I** |
| 0 1 | 0 | 0 | **I** | 0 |
| 1 0 | 0 | **I** | 0 | 0 |
| 1 1 | **I** | 0 | 0 | 0 |

```
            ┌──────────┐──► y[0]
    I ─────►│  1 對 4   │──► y[1]
            │  DEMUX   │──► y[2]
            └──────────┘──► y[3]
               ▲    ▲
               S1   S0
```

---

## 2. 檔案說明

### demul1_4_if.v
```verilog
always @(*) begin
    if (S1 == 1'b0) begin
        if (S0 == 1'b0) y = {3'b000, I};         // 00
        else            y = {2'b00, I, 1'b0};    // 01
    end
    else begin
        if (S0 == 1'b0) y = {1'b0, I, 2'b00};    // 10
        else            y = {I, 3'b000};         // 11
    end
end
```
- 外層 `if` 看 S1，內層 `if` 看 S0，共 4 條路徑。
- 用**連結運算子** `{ }` 把 `I` 放到對應的位元（week03 的 14_Concate）。
- 埠順序和講義相同：`(y, I, S0, S1)`，輸出放第一個。

### demul1_4_if_tb.v（講義第 29 頁）
- 3 位元計數器 `data` 每個時脈正緣加 1，拆成 `I = data[2]`、`S1 = data[1]`、`S0 = data[0]`，
  8 個時脈就跑完所有組合。
- 講義沒寫結束條件，這裡加上 `#170 $stop`。

## 3. 預期輸出

```
t=0    I=0 S1=0 S0=0  ->  y=0000
t=10   I=0 S1=0 S0=1  ->  y=0000
t=30   I=0 S1=1 S0=0  ->  y=0000
t=50   I=0 S1=1 S0=1  ->  y=0000
t=70   I=1 S1=0 S0=0  ->  y=0001
t=90   I=1 S1=0 S0=1  ->  y=0010
t=110  I=1 S1=1 S0=0  ->  y=0100
t=130  I=1 S1=1 S0=1  ->  y=1000
t=150  I=0 S1=0 S0=0  ->  y=0000   ← data 從 111 回到 000
```

### 觀察重點
- I = 1 時，那個 1 依序出現在 y[0] → y[1] → y[2] → y[3]，和講義第 28 頁波形的 0001、0010、0100、1000 相同。
- I = 0 時不管選哪一個，y 都是 0000。

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 解多工器 | 1 個輸入分配到 2ⁿ 個輸出之一 |
| 巢狀 if | 外層、內層各判斷一條選擇線 |
| 連結運算子 `{ }` | 組出指定位元為 I、其餘為 0 的向量 |
| 計數器產生測試向量 | 把計數器的位元拆開當各個輸入 |
