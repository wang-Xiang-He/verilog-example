# 13_For_Loop 範例說明：for 迴圈

## 1. 這個範例在做什麼？

講義第 42 頁的 for 迴圈範例：

- `Out[i] = a[i] ^ b[i]`：4 個位元逐一做 XOR
- `c`：每一位 `(a[i] | b[i])` 全部 AND 起來

重點是：**可合成的 for 迴圈在編譯時就被展開**成重複的電路，不是像 C 語言一樣執行時一圈一圈跑。

---

## 2. 檔案說明

### For_XOR.v
```verilog
always @(*) begin : for_loop_test
    integer i;
    c = 1'b1;
    for (i = 0; i <= 3; i = i + 1) begin
        Out[i] = a[i] ^ b[i];
        c = (a[i] | b[i]) & c;
    end
end
```
- `begin : for_loop_test`：替區塊取名字，才能在區塊內宣告區域變數 `integer i`。
- `integer`：32 位元有號整數，常用來當迴圈變數，不會變成實際的硬體。

### 展開後的等效寫法
```verilog
Out[0] = a[0] ^ b[0];
Out[1] = a[1] ^ b[1];
Out[2] = a[2] ^ b[2];
Out[3] = a[3] ^ b[3];
c = (a[0] | b[0]) & (a[1] | b[1]) & (a[2] | b[2]) & (a[3] | b[3]);
```
（其實 `Out` 部分直接寫 `Out = a ^ b;` 就好，for 迴圈適合每一位規則相同、但寫起來很長的情況。）

### 和講義不同：c 的初值
講義寫 `c = (a[i] | b[i]) & c;` 但**沒有給 c 初值**，展開後的最後一項 `& c` 用到的是 c **上一次的值** →
輸出接回輸入形成迴授，組合邏輯中會變成 Latch（甚至震盪）。而且 c 一旦變成 0 就永遠是 0。
這裡在迴圈前加上 `c = 1'b1;`（1 是 AND 的單位元素），c 就單純等於每一位 `a|b` 的 AND。

---

## 3. 預期輸出

```
t=0   a=1100 b=1010  ->  Out=a^b=0110  c=0   ← 第 0 位 a|b = 0|0 = 0
t=10  a=1100 b=0010  ->  Out=a^b=1110  c=0
t=20  a=1111 b=1111  ->  Out=a^b=0000  c=1
t=30  a=0000 b=1111  ->  Out=a^b=1111  c=1
```

### 觀察重點
- 第一行 1100 | 1010 = 1110，第 0 位是 0，所以 c = 0。
- 只有每一位都至少有一個 1 時 c 才是 1。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| for 迴圈 | 編譯時展開，迴圈次數必須是常數 |
| `integer` | 迴圈變數，不產生硬體 |
| 具名區塊 `begin : 名稱` | 才能在區塊內宣告變數 |
| 組合邏輯中讀自己的舊值 | 會產生 Latch / 迴授，要先給初值 |
