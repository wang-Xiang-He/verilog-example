# 11_Decoder 範例說明：3 對 8 解碼器（左移運算子）

## 1. 這個範例在做什麼？

設計 **3 對 8 解碼器**：3 位元輸入 `in`（0~7），8 位元輸出 `Out` 中**第 `in` 位為 1**，其餘為 0。

和 [07_Deco2_4g](../07_Deco2_4g/deco2_4g_說明.md) 功能相同（只是更大），
但這次只用**一行資料流描述**，展示左移運算子的巧妙用法。

---

## 2. 檔案說明

### Decoder.v
```verilog
input  [2:0] in;
output [7:0] Out;

assign Out = 1'b1 << in;
```

**原理**：把數字 1 向左移 `in` 位，1 就剛好跑到第 `in` 個位元。

```
in = 0  →  0000_0001
in = 1  →  0000_0010
in = 2  →  0000_0100
...
in = 7  →  1000_0000
```

#### 為什麼 `1'b1` 左移不會被截掉？
`1'b1` 只有 1 位元，照理說左移後會變 0。
但 Verilog 計算運算式時，會**依等號左邊（`Out`，8 位元）的寬度**來擴展運算元，
所以 `1'b1` 先被擴展成 `0000_0001` 再左移，結果正確。

### 對比 07 範例

| 寫法 | 程式量 |
|------|--------|
| 邏輯閘層次（07） | 2 個 NOT + 4 個 AND，2 對 4 就要 6 行 |
| 資料流 + 移位（本例） | 1 行，擴展到 4 對 16 也只要改宣告寬度 |

### Decoder_tb.v
用 `for` 迴圈讓 `in` 跑 0~7。

---

## 3. 預期輸出

```
t=0   in=000(0)  ->  Out=00000001
t=10  in=001(1)  ->  Out=00000010
t=20  in=010(2)  ->  Out=00000100
t=30  in=011(3)  ->  Out=00001000
t=40  in=100(4)  ->  Out=00010000
t=50  in=101(5)  ->  Out=00100000
t=60  in=110(6)  ->  Out=01000000
t=70  in=111(7)  ->  Out=10000000
```

### 觀察重點
- 輸出永遠只有一個 1（稱為 **one-hot** 編碼）。
- 1 的位置從右往左數（從 0 開始）剛好等於 `in` 的值。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `1 << n` | 產生第 n 位為 1 的 one-hot 值 |
| 運算寬度 | 運算式依等號兩邊最寬的寬度計算 |
| 解碼器 | n 位元輸入 → 2ⁿ 條輸出 |
| 資料流描述 | 用運算子描述，比閘層次簡潔 |
