# 02_FullAdd4 範例說明：4 位元漣波進位加法器（Ripple Carry Adder）

## 1. 這個範例在做什麼？

把 [01_FullAdd](../01_FullAdd/FullAdd_說明.md) 的 1 位元全加器**複製 4 份串起來**，做成 4 位元加法器：

```
Sum[3:0], Carry_Out = a[3:0] + b[3:0] + Carry_In
```

這是**階層式設計**的第一個例子：上層模組 `FullAdd4` 裡面「實例化」了 4 個下層模組 `FullAdd`。

---

## 2. 電路架構

```
           a[3] b[3]        a[2] b[2]        a[1] b[1]        a[0] b[0]
             │   │            │   │            │   │            │   │
            ┌▼───▼┐          ┌▼───▼┐          ┌▼───▼┐          ┌▼───▼┐
Carry_Out ◄─┤ fa3 │◄─────────┤ fa2 │◄─────────┤ fa1 │◄─────────┤ fa0 │◄── Carry_In
            └──┬──┘Carry_Out3└──┬──┘Carry_Out2└──┬──┘Carry_Out1└──┬──┘
               ▼                ▼                ▼                ▼
             Sum[3]           Sum[2]           Sum[1]           Sum[0]
```

每一級的 `Carry_Out` 接到下一級的 `Carry_In`。
「**漣波**（ripple）」的意思是：進位像水波一樣從最低位一級一級往上傳。

---

## 3. 檔案說明

| 檔案 | 用途 |
|------|------|
| `FullAdd.v` | 1 位元全加器（和 01 範例相同） |
| `FullAdd4.v` | 4 位元加法器，實例化 4 個 FullAdd |
| `FullAdd4_tb.v` | 測試平台 |

### FullAdd4.v
```verilog
input  [3:0] a, b;                          // [3:0] = 4 位元向量，a[3] 最高位
wire Carry_Out1, Carry_Out2, Carry_Out3;    // 內部串接用的進位

FullAdd fa0 (a[0], b[0], Carry_In,   Sum[0], Carry_Out1);
FullAdd fa1 (a[1], b[1], Carry_Out1, Sum[1], Carry_Out2);
FullAdd fa2 (a[2], b[2], Carry_Out2, Sum[2], Carry_Out3);
FullAdd fa3 (a[3], b[3], Carry_Out3, Sum[3], Carry_Out);
```

- **實例化語法**：`模組名 實例名 (連接的訊號);`，例如 `FullAdd fa0 (...)`。
  同一個模組可以實例化很多次，每一份都是獨立的硬體。
- 這裡用**依順序**連接：括號內的順序必須和 `FullAdd` 宣告的 `(a, b, Carry_In, Sum, Carry_Out)` 一致。
- `a[0]`：取向量的單一位元。
- `Carry_Out1~3` 是**模組內部的連線**，必須宣告成 `wire`。
  講義漏寫了這行；Verilog 遇到沒宣告的名字會自動當成 1 位元 wire，這裡剛好能動，
  但若是多位元訊號就會出錯，所以**養成一定要宣告的習慣**。

### FullAdd4_tb.v
```verilog
wire [4:0] total = {Carry_Out, Sum};   // 5 位元完整結果
```
把進位接在最前面組成 5 位元，印成十進位方便對照算式是否正確。

## 4. 預期輸出

```
t=0   a=0000 b=0000 Cin=0  ->  Cout=0 Sum=0000  (0 + 0 + 0 = 0)
t=10  a=0000 b=0000 Cin=1  ->  Cout=0 Sum=0001  (0 + 0 + 1 = 1)
t=20  a=0000 b=1111 Cin=0  ->  Cout=0 Sum=1111  (0 + 15 + 0 = 15)
t=30  a=0000 b=1111 Cin=1  ->  Cout=1 Sum=0000  (0 + 15 + 1 = 16)
t=40  a=0101 b=0011 Cin=0  ->  Cout=0 Sum=1000  (5 + 3 + 0 = 8)
t=50  a=1111 b=1111 Cin=1  ->  Cout=1 Sum=1111  (15 + 15 + 1 = 31)
```

### 觀察重點
- **t=30**：`1111 + 1` 時，進位從 fa0 一路傳到 fa3，最後 `Carry_Out = 1`、`Sum = 0000`。
  這是漣波加法器**最慢**的情況（實際硬體中位數越多，進位傳遞延遲越長）。
- **t=50**：最大值 15 + 15 + 1 = 31 = `1_1111`，5 位元剛好放得下。
- 波形視窗裡，向量訊號可以右鍵 **Radix > Unsigned** 改成十進位顯示。
- 在 sim 視窗點開 `uut`，可以把內部的 `Carry_Out1~3` 加進波形觀察進位傳遞。

---

## 5. 重點整理

| 觀念 | 說明 |
|------|------|
| 向量 `[3:0]` | 多位元訊號，`[3]` 為最高位 |
| 實例化 | 同一模組可放多份，每份是獨立硬體 |
| 依順序連接 | 訊號順序要和子模組宣告的埠順序一致 |
| 內部 wire | 子模組之間的連線要宣告成 `wire` |
| 漣波進位 | 進位一級一級傳遞，位數多時延遲大 |
