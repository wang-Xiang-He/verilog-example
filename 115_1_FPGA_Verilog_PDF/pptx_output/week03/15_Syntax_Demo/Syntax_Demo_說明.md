# 15_Syntax_Demo 範例說明：基本語法（數值、字串、$display / $write）

## 1. 這個範例在做什麼？

這個範例**沒有電路**，只有一個 testbench，用 `$display` 把講義裡的語法例子印出來，
讓你實際看到各種數值寫法、字串、顯示函式的結果。

重點看 **Transcript 視窗的文字輸出**，不需要看波形。

---

## 2. 數值表示法

### 定長度數字
```
<位元數>'<進位制><數值>
```

| 進位制 | 符號 | 例子 | 十進位 |
|--------|------|------|--------|
| 二進位 | `b` | `8'b1010_1010` | 170 |
| 八進位 | `o` | `9'o377` | 255 |
| 十進位 | `d` | `10'd128` | 128 |
| 十六進位 | `h` | `16'h89Ab` | 35243（大小寫皆可） |

程式中把每個數字左移 1 位（= 乘以 2），結果存回**同樣寬度**的變數：

```
16'h89Ab << 1     = 1356 (hex)      ← 0x11356 超過 16 位元，最高位的 1 被丟掉
10'd128 << 1      = 256 (dec)       ← 10 位元放得下
9'o377 << 1       = 776 (oct)       ← 255×2 = 510 = 八進位 776
8'b10101010 << 1  = 01010100 (bin)  ← 最高位的 1 被擠掉
```
**重點**：結果寬度不夠時，高位會被**截掉**（溢位）。

### 不定長度數字
```verilog
U = 'h89Ab;    // 沒寫位元數 → 預設 32 位元
```
```
'h89Ab (unsized)  = 00000000000000001000100110101011 (32 bits)
```
沒寫進位制（例如直接寫 `100`）則預設為**十進位**。

### 負數
```verilog
Out4 = -8'd79;
```
```
-8'd79 = 10110001 = 177 (as unsigned)
```
- 負號要寫在**最前面**（`-8'd79`，不能寫 `8'd-79`）。
- 存成 79 的 **2 的補數**：256 − 79 = 177 = `1011_0001`。

### 底線 `_` 與問號 `?`
```verilog
W = 12'b1010_1111_0101;   // 底線只是方便閱讀，編譯時忽略
Q = 8'b11??11??;          // ? 等於 z（高阻抗）
```
```
12'b1010_1111_0101 = 101011110101
8'b11??11??        = 11zz11zz  (? = z)
```
`?` 常用在 `casez` 裡表示「不在乎（don't care）」。

### 四種邏輯值
| 值 | 意義 |
|----|------|
| `0` | 邏輯 0 |
| `1` | 邏輯 1 |
| `x` | 未知（例如未初始化、多個來源衝突） |
| `z` | 高阻抗（沒有驅動，像斷線） |

## 3. 字串

```verilog
reg [8*18-1:0] stringvar;          // 18 個字元 × 8 位元
stringvar = "Hello Verilog HDL!";
$display("stringvar = %s", stringvar);
```
- Verilog 沒有字串型態，字串存在 `reg` 裡，**每個字元佔 8 位元**（ASCII）。
- 用 `%s` 顯示。

---

## 4. 顯示函式

### $display vs $write

| 函式 | 自動換行 | 預設進位制 |
|------|----------|-----------|
| `$display` | 會 | 十進位 |
| `$write` | **不會** | 十進位 |
| `$displayh` / `$writeh` | 會 / 不會 | 十六進位 |
| `$displayb` / `$writeb` | 會 / 不會 | 二進位 |
| `$displayo` / `$writeo` | 會 / 不會 | 八進位 |

```verilog
$display($time);                    // 印出目前時間（固定寬度，前面有空白）
$display("The data is %b", data1);  // The data is 0101
$write(4'b1111);                    // 15（不換行）
$write(" ", 5'b10101);              //  21（不換行）
$writeh(" ", 5'b01111, "\n");       //  0f（十六進位，手動加 \n 換行）
```
最後三行合起來印在同一行：`15 21 0f`。

### 格式符號

| 符號 | 意義 |
|------|------|
| `%b` | 二進位 |
| `%o` | 八進位 |
| `%d` | 十進位（`%0d` 不補前導空白） |
| `%h` | 十六進位 |
| `%s` | 字串 |
| `%t` | 時間 |

## 6. 重點整理

| 觀念 | 說明 |
|------|------|
| 定長度數字 | `寬度'進位制數值`，例如 `8'hFF` |
| 不定長度 | 預設 32 位元、十進位 |
| 截斷 | 結果超出變數寬度時高位被丟掉 |
| 負數 | 負號放最前面，存成 2 的補數 |
| `_` / `?` | 底線提升可讀性；`?` 等於 z |
| 字串 | 存在 reg 中，每字元 8 位元 |
| `$display` / `$write` | 差在會不會自動換行 |
