# 09_Compare 範例說明：比較器（關係 / 等式運算子）

## 1. 這個範例在做什麼？

比較兩個 8 位元數 `a`、`b` 的大小，三個輸出中**恰好一個為 1**：

| 輸出 | 條件 |
|------|------|
| `larger` | a > b |
| `equal` | a == b |
| `less` | a < b |

---

## 2. 檔案說明

### Comparator.v
```verilog
module Comparator #(
    parameter size = 8
) (
    input  [size-1:0] a,
    input  [size-1:0] b,
    output            larger,
    output            equal,
    output            less
);
    assign larger = (a >  b);   // 關係運算子（Relational）
    assign equal  = (a == b);   // 等式運算子（Equality）
    assign less   = (a <  b);
endmodule
```

- 比較運算的結果是 **1 位元**：成立為 `1`、不成立為 `0`，可以直接接到 1 位元輸出。
- 一樣用 `parameter size` 讓寬度可調（見 [08_AddOrSub](../08_AddOrSub/Add_or_Subtract_說明.md)）。

### 運算子一覽

| 類別 | 運算子 | 說明 |
|------|--------|------|
| 關係 | `>` `<` `>=` `<=` | 大小比較 |
| 等式 | `==` `!=` | 相等 / 不相等；若有 x 或 z，結果為 **x** |
| 全等 | `===` `!==` | 連 x、z 都逐位比較，結果一定是 0 或 1（**只用於模擬**） |

> 注意：`<=` 放在**運算式裡**是「小於等於」，放在 `always` 裡當敘述則是「非阻隔式賦值」，要看位置判斷。

> 注意：這裡的 a、b 是**無號數**比較。若宣告為 `signed`，`8'b1111_1111` 會被當成 −1。

### Comparator_tb.v
測試三種情況：a > b、a = b、a < b。

---

## 3. 預期輸出

```
t=0   a=11111111(255) b=00000001(1)    ->  larger=1 equal=0 less=0
t=10  a=00111111(63)  b=00111111(63)   ->  larger=0 equal=1 less=0
t=20  a=00000011(3)   b=11001000(200)  ->  larger=0 equal=0 less=1
```

### 觀察重點
- 三個輸出**恰好一個是 1**（互斥）。
- 255 > 1 成立，表示以**無號數**比較。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 關係運算子 | `>` `<` `>=` `<=`，結果 1 位元 |
| 等式運算子 | `==` `!=`；遇到 x/z 結果為 x |
| 全等運算子 | `===` `!==`；testbench 比對結果常用 |
| 無號 / 有號 | 預設無號數比較 |
