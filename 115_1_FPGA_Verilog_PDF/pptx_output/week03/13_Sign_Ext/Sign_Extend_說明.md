# 13_Sign_Ext 範例說明：符號位元擴展（重複運算子）

## 1. 這個範例在做什麼？

把 8 位元資料 `Word` 擴展成 16 位元 `Double`，高 8 位元要補什麼由 `SignExtend` 決定：

| SignExtend | 高 8 位補 | 用途 |
|------------|-----------|------|
| 1 | `Word[7]`（符號位元）重複 8 次 | **有號數**擴展，數值不變 |
| 0 | 8 個 0 | **無號數**擴展，數值不變 |

重點在於介紹**重複運算子** `{n{...}}`。

---

## 2. 為什麼需要符號擴展？

有號數用 **2 的補數** 表示，最高位元是**符號位元**（0 = 正、1 = 負）。

以 `1100_0011` 為例（有號數 = −61）：

| 擴展方式 | 16 位元結果 | 當有號數看 |
|----------|-------------|-----------|
| 補 0 | `0000_0000_1100_0011` | **195**（錯，變成正數了） |
| 補符號位元 | `1111_1111_1100_0011` | **−61**（正確） |

所以負數要補 1、正數要補 0，也就是**補符號位元**。
CPU 把 8 位元有號數載入 16 / 32 位元暫存器時就是這樣做。

---

## 3. 檔案說明

### Sign_Extend.v
```verilog
module Sign_Extend (
    input             SignExtend,
    input      [7:0]  Word,
    output reg [15:0] Double        // 在 always 裡被賦值 → reg
);
    always @(*) begin               // 任一輸入改變就重新計算
        if (SignExtend)
            Double = {{8{Word[7]}}, Word};   // 符號擴展
        else
            Double = {8'b0, Word};           // 補 0
    end
endmodule
```

#### 重複運算子 `{n{x}}`
把 `x` 重複 `n` 次：
```verilog
{8{Word[7]}}   // Word[7] 重複 8 次；若 Word[7]=1 → 8'b1111_1111
{4{2'b10}}     // → 8'b1010_1010
```
注意外層還要再包一層連結運算子：`{ {8{Word[7]}}, Word }`。

#### 用 always 描述組合邏輯
- 敏感清單 `@(*)`：由編譯器自動列出區塊內讀到的**所有輸入**，任一改變就重算 → 這是**組合邏輯**，不是正反器。
  講義寫的是 `@(SignExtend or Word)`（手動列出），功能相同；但手寫時漏列一個輸入，
  模擬結果就會和合成出的硬體不一致，所以 Verilog-2001 以後建議一律用 `@(*)`。
- 組合邏輯的 `always` 用**阻隔式 `=`** 是正確的（和正反器用 `<=` 相反）。
- `if-else` 要寫完整，否則會合成出不想要的 **latch（閂鎖器）**。

### Sign_Extend_tb.v
```verilog
wire signed [15:0] Double_s = Double;   // 同一組位元，用有號數方式解讀
```
`signed` 讓 `%d` 把最高位當符號位元，方便確認數值有沒有保持正確。

---

## 4. 預期輸出

```
t=0   SignExtend=1 Word=11000011  ->  Double=1111111111000011  (signed -61)
t=10  SignExtend=0 Word=11000011  ->  Double=0000000011000011  (signed 195)
t=20  SignExtend=1 Word=00001111  ->  Double=0000000000001111  (signed 15)
t=30  SignExtend=1 Word=10001111  ->  Double=1111111110001111  (signed -113)
```

### 觀察重點
- **t=0 vs t=10**：同一個 Word，符號擴展得到 −61（原值），補 0 得到 195（被當成無號數）。
- **t=20**：正數（最高位 0）做符號擴展，補的也是 0，結果和補 0 一樣。
- **t=30**：負數 `1000_1111`（−113）符號擴展後仍是 −113。

---

## 5. 重點整理

| 觀念 | 說明 |
|------|------|
| 重複運算子 `{n{x}}` | 把 x 重複 n 次，外面常再包一層 `{ }` |
| 符號擴展 | 高位補符號位元，有號數值不變 |
| 零擴展 | 高位補 0，無號數值不變 |
| 組合邏輯 always | 敏感清單列所有輸入（或用 `@(*)`），用 `=` |
| `signed` | 宣告為有號數，影響顯示與比較、右移的行為 |
