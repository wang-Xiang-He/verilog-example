# 08_AddOrSub 範例說明：加減法器（parameter + 條件運算子）

## 1. 這個範例在做什麼？

依控制訊號 `op` 選擇做加法或減法：

- `op = 1`（ADD）→ `s = a + b`
- `op = 0` → `s = a - b`

重點在介紹 **`parameter`（參數）**，以及用**條件運算子**在兩種結果中擇一。

---

## 2. 檔案說明

### Add_or_Subtract.v
```verilog
module Add_or_Subtract #(
    parameter SIZE = 8,
    parameter ADD  = 1'b1
) (
    input  [SIZE-1:0] a,
    input  [SIZE-1:0] b,
    input             op,
    output [SIZE-1:0] s
);
    assign s = (op == ADD) ? a + b : a - b;
endmodule
```

#### parameter 參數
- `parameter` 是**模組內的常數**，編譯時就決定，不是訊號。
- Verilog-2001 寫法把參數放在模組名後面的 `#( ... )` 裡（參數之間用**逗號**分隔），
  這樣後面的埠宣告才能用到 `SIZE`。
  講義是舊寫法：`module Add_or_Subtract (a, b, op, s);` 後面再寫 `parameter SIZE = 8;`。
- `SIZE = 8`：位元寬度寫成 `[SIZE-1:0]`，想改成 16 位元只要改一個地方。
- `ADD = 1'b1`：給常數取有意義的名字，`op == ADD` 比 `op == 1` 好讀。
- 實例化時可以**覆寫參數**，同一個模組做出不同寬度的電路：
  ```verilog
  Add_or_Subtract #(.SIZE(16)) u16 (.a(...), .b(...), .op(...), .s(...));
  ```

#### 條件運算子 `? :`
```
條件 ? 成立時的值 : 不成立時的值
```
對應到硬體是：一個加法器、一個減法器，最後接一個**多工器**選其中一個結果。

#### 溢位
結果 `s` 只有 `SIZE` 位元，超出的進位 / 借位**直接丟掉**：
- 255 + 1 = 256 = `1_0000_0000`，只留低 8 位 → `0000_0000`。
- 3 − 5 = −2，以 8 位元 **2 的補數** 表示為 `1111_1110`，當無號數看是 254。

### Add_or_Subtract_tb.v
testbench 實例化時沒有覆寫參數，所以使用預設的 `SIZE = 8`。

## 3. 預期輸出

```
t=0   op=1  a=11111111(255) b=00000001(1)  ->  s=00000000(0)     ← 加法溢位
t=10  op=0  a=00111111(63)  b=00000101(5)  ->  s=00111010(58)    ← 63 - 5
t=20  op=1  a=01100100(100) b=00010111(23) ->  s=01111011(123)   ← 100 + 23
t=30  op=0  a=00000011(3)   b=00000101(5)  ->  s=11111110(254)   ← 3 - 5 = -2
```

### 觀察重點
- **t=0**：255 + 1 應該是 256，但 8 位元放不下，結果變 0（**溢位**）。
  如果要保留進位，輸出要多 1 位元，例如 `output [SIZE:0] s`。
- **t=30**：3 − 5 = −2，硬體中存成 `11111110`。
  - 當**無號數**看 = 254
  - 當**有號數（2 的補數）**看 = −2
  - 位元完全一樣，差別只在「怎麼解讀」。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `parameter` | 模組內常數，可在實例化時用 `#( )` 覆寫 |
| 參數化寬度 | `[SIZE-1:0]` 讓模組可重複使用 |
| 條件運算子 `? :` | 二選一，合成為多工器 |
| 溢位 | 結果超出位元寬度時高位被截掉 |
| 2 的補數 | 負數的表示法；同一組位元可當有號或無號解讀 |
