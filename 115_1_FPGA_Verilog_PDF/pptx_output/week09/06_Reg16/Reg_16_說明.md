# 06_Reg16 範例說明：具有清除訊號的 16 位元「暫存器」

## 1. 這個範例在做什麼？

### 暫存器（講義第 13 頁）
- **暫存器**是一群二進位存取單元的集合，可用來儲存二進位資料。
- 每一個存取單元通常為一個**正反器**，可以存取一個位元的資料。
- 一個具有 n 個位元的暫存器，共可存取 n 個位元資料。

本範例：具有「清除」訊號的 16 位元暫存器。

```
            16
  Reg_In ──/──►┌──────┐  16
               │ Reg  │──/──► Reg_Out
  Clear ──────►│  16  │
               └──────┘
```

| Clear | Reg_Out |
|-------|---------|
| 0 | 0（清為 0） |
| 1 | Reg_In（載入資料） |

> 講義第 13 頁方塊圖的輸出寫 8，但程式是 16 位元，以程式為準。

---

## 2. 程式說明

### Reg_16.v（講義第 13 頁）
```verilog
module Reg_16 (
    input             Clear,
    input      [16:1] Reg_In,
    output reg [16:1] Reg_Out
);
    always @(*) begin               // 講義：always @(Clear or Reg_In)（event list）
        case (Clear)
            1'b0: Reg_Out[16:1] = 16'b0;            // 清為 0
            1'b1: Reg_Out[16:1] = Reg_In[16:1];     // 載入資料
        endcase
    end
endmodule
```

### `[16:1]`：位元編號不一定從 0 開始
`[16:1]` 是位元 16 到位元 1，共 **16 - 1 + 1 = 16 位元**（講義第 13 頁紅字）。
最常見的是 `[15:0]`；`[16:1]` 一樣是 16 位元，只是編號從 1 開始。

---

## 3. 這其實不是暫存器

仔細看敏感清單：`@(Clear or Reg_In)`。**沒有時脈**。
- Clear = 0 → Reg_Out = 0
- Clear = 1 → Reg_Out = Reg_In，Reg_In 一變 Reg_Out **立刻**跟著變

兩種情況輸出都**直接由現在的輸入決定**，沒有「記住」任何東西，所以這是**組合邏輯**：一個 AND 閘陣列（`Reg_Out = Reg_In & {16{Clear}}`）。

只有一種情況會「保持」：**Clear 是 x 或 z** 時，case 的兩個項目都比對不到，Reg_Out 保持舊值，這時才像 latch。

真正的暫存器要在時脈邊緣才存值，例如下一個範例 [07_Reg4_Async_Sync](../07_Reg4_Async_Sync/Reg4_說明.md)：
```verilog
always @(posedge Clock)
    if (!Clear) Reg_Out <= 0;
    else        Reg_Out <= Reg_In;
```

---

## 4. 預期輸出

數值和講義第 14 頁的波形相同（0101、0010、0011）：

```
t=0   Clear=0  Reg_In=0000000000000101  ->  Reg_Out=0000000000000000   ← 清為 0
t=10  Clear=1  Reg_In=0000000000000101  ->  Reg_Out=0000000000000101   ← 載入
t=20  Clear=1  Reg_In=0000000000000010  ->  Reg_Out=0000000000000010   ← Reg_In 一變就跟著變
t=30  Clear=x  Reg_In=0000000000000010  ->  Reg_Out=0000000000000010
t=40  Clear=x  Reg_In=0000000000000011  ->  Reg_Out=0000000000000010   ← Clear=x：保持（不跟著變）
t=50  Clear=1  Reg_In=0000000000000011  ->  Reg_Out=0000000000000011
```

### 觀察重點
- t=20：Reg_In 改變的同一時間，Reg_Out 就變了，不必等任何時脈。這證明它是組合邏輯。
- t=40：只有 Clear = x 時，Reg_Out 才停在舊值。

---

## 5. 重點整理

| 觀念 | 說明 |
|------|------|
| 暫存器 | n 個正反器組成，存 n 位元 |
| `[16:1]` | 位元編號可以不從 0 開始，寬度 = 高 - 低 + 1 |
| 沒有時脈 | 就不是暫存器，而是組合邏輯 |
| case 沒比對到 | 輸出保持舊值（latch 行為） |
