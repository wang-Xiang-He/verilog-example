# 08_Dataflow_Delay1 範例說明：資料流描述的個別延遲（範例練習 7-002）

## 1. 這個範例在做什麼？

和 [07_Gate_Delay](../07_Gate_Delay/gate_delay1_說明.md) **完全相同的電路、相同的延遲**，
只是從「邏輯閘層」改成「**資料流描述**」：用 `assign` 和運算子，延遲寫在 `assign` 後面（講義第 23、24 頁）。

```
a1 ─┐
    &  #4 ── y1 ─┐
a2 ─┘            │
                 |  #10 ── y
a3 ─┐            │
    &  #6 ── y2 ─┘
a4 ─┘
```

---

## 2. 程式說明

### dataflow_delay1.v（講義第 24 頁）
```verilog
module dataflow_delay1 (
    input  a1,
    input  a2,
    input  a3,
    input  a4,
    output y
);
    wire y1, y2;

    assign #4  y1 = a1 & a2;
    assign #6  y2 = a3 & a4;
    assign #10 y  = y1 | y2;
endmodule
```

語法：
```
assign #延遲 目標 = 運算式;
```
運算式的結果，要等 `#延遲` 之後才會指定給目標。

### 和 07 的對照

| 07 邏輯閘層 | 08 資料流 |
|------------|-----------|
| `and #4 and1 (y1, a1, a2);` | `assign #4 y1 = a1 & a2;` |
| `and #6 and2 (y2, a3, a4);` | `assign #6 y2 = a3 & a4;` |
| `or #10 or1 (y, y1, y2);` | `assign #10 y = y1 \| y2;` |

`assign` 的延遲一樣是**慣性延遲**：輸入變化如果比延遲還短，就會被濾掉（見 07 說明第 4 節）。

> 講義第 24 頁的電路圖中，每個 assign 被畫成一個圓圈（`#ASSIGN#7`、`#ASSIGN#8`、`#ASSIGN#9`），
> 這是模擬器替沒有名字的 assign 自動取的名稱。

## 3. 預期輸出

**每一行都和 07_Gate_Delay 一模一樣**（節錄）：
```
t=0    a1=0 a2=0 a3=0 a4=0  |  y1=x y2=x  |  y=x
t=4    ...                  |  y1=0 y2=x  |  y=x
t=6    ...                  |  y1=0 y2=0  |  y=x
t=16   ...                  |  y1=0 y2=0  |  y=0
t=20   a1=1 a2=1 a3=0 a4=0  |  y1=0 y2=0  |  y=0
t=24   a1=1 a2=1 a3=0 a4=0  |  y1=1 y2=0  |  y=0
t=34   a1=1 a2=1 a3=0 a4=0  |  y1=1 y2=0  |  y=1    ← 14ns
...
t=60   a1=0 a2=0 a3=1 a4=1  |  y1=0 y2=0  |  y=0
t=66   a1=0 a2=0 a3=1 a4=1  |  y1=0 y2=1  |  y=0
t=76   a1=0 a2=0 a3=1 a4=1  |  y1=0 y2=1  |  y=1    ← 16ns
...
```
完整輸出在 `dataflow_delay1_tb.v` 檔尾。

### 觀察重點
- 用運算子還是用邏輯閘描述，只是寫法不同；同樣的延遲得到同樣的波形。
- 資料流寫法比較短，運算式複雜時（例如 `assign #5 y = (a & b) | (c ^ d);`）比一顆一顆接邏輯閘方便。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `assign #延遲 目標 = 運算式;` | 資料流描述的延遲 |
| 和 `and #4` 等效 | 行為完全相同 |
| 慣性延遲 | assign 的延遲也會濾掉太短的脈波 |
