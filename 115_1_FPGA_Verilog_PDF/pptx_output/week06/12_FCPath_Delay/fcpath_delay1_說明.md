# 12_FCPath_Delay 範例說明：完全連接路徑延遲 *>（範例練習 7-006）

## 1. 這個範例在做什麼？

和 [11_PPath_Delay](../11_PPath_Delay/ppath_delay1_說明.md) 相同的電路、相同的路徑延遲，
改用**完全連接路徑** `*>` 來寫，四行縮成兩行（講義第 36~38 頁）。

| 路徑 | 延遲 |
|------|------|
| a1、a2 → y | 10 |
| a3、a4 → y | 12 |

---

## 2. 程式說明

### fcpath_delay1.v（講義第 37 頁）
```verilog
module fcpath_delay1 (
    input  a1,
    input  a2,
    input  a3,
    input  a4,
    output y
);
    wire y1, y2;

    specify
        (a1, a2 *> y) = 10;
        (a3, a4 *> y) = 12;
    endspecify

    and and1 (y1, a1, a2);
    and and2 (y2, a3, a4);
    or  or1  (y,  y1, y2);
endmodule
```

語法：
```
(來源1, 來源2, ... *> 目的1, 目的2, ...) = 延遲;
```
**每一個來源的每一個位元**，到**每一個目的的每一個位元**，都設成這個延遲。

所以：
```verilog
(a1, a2 *> y) = 10;
```
等於 11 範例的兩行：
```verilog
(a1 => y) = 10;
(a2 => y) = 10;
```

### => 和 *> 什麼時候不一樣？

本範例的輸入輸出都是 **1 位元**，兩種寫法結果完全一樣。差別出現在**向量**：

```verilog
input  [1:0] a;
output [1:0] q;

specify
    (a => q) = 5;   // 並列：a[0]→q[0]、a[1]→q[1]，共 2 條路徑；a 和 q 的位元數必須一樣
    (a *> q) = 5;   // 完全連接：a[0]→q[0]、a[0]→q[1]、a[1]→q[0]、a[1]→q[1]，共 4 條路徑
endspecify
```

| | `=>` 並列 | `*>` 完全連接 |
|---|---|---|
| 對應方式 | 第 i 位 → 第 i 位 | 每一位 → 每一位 |
| 位元數 | 來源和目的必須相同 | 可以不同 |
| 一行可寫幾個來源 | 1 個 | 很多個（用逗號分開） |
| 適合 | 每個位元各自獨立的電路（例如緩衝器） | 每個輸入都會影響每個輸出的電路（例如加法器） |

### 觀察重點
- 和講義第 38 頁的 #10、#12 相同。
- `*>` 一行就能把好幾個輸入一起設定，輸入多的時候比較省事。

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `(來源1, 來源2 *> 目的) = 延遲;` | 完全連接路徑 |
| 1 位元時 | `=>` 和 `*>` 結果一樣 |
| 向量時 | `=>` 一位對一位；`*>` 每一位對每一位 |
