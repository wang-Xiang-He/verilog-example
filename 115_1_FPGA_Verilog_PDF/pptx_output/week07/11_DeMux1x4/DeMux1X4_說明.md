# 11_DeMux1x4 範例說明：1 對 4 解多工器（assign 與 if ... else）

## 1. 這個範例在做什麼？

把 [10_DeMux1x2](../10_DeMux1x2/DeMux1X2_說明.md) 擴大成 **1 對 4**（講義第 49~51 頁）：
兩條選擇線 `S1 S0` 決定 D 送到 Y0~Y3 的哪一條。

典型的 **1×2ⁿ 解多工器**具有 n 條選擇線，以及 2ⁿ 條輸出線（講義第 44 頁）。

| S1 | S0 | Y0 | Y1 | Y2 | Y3 |
|----|----|----|----|----|----|
| 0 | 0 | D | 0 | 0 | 0 |
| 0 | 1 | 0 | D | 0 | 0 |
| 1 | 0 | 0 | 0 | D | 0 |
| 1 | 1 | 0 | 0 | 0 | D |

布林方程式（講義第 49 頁）：
```
Y0 = S1'．S0'．D
Y1 = S1'．S0 ．D
Y2 = S1 ．S0'．D
Y3 = S1 ．S0 ．D
```

---

## 2. 兩種寫法

### DeMux1X4_1：assign（講義第 50 頁）
```verilog
assign Y0 = (!S1) & (!S0) & D;
assign Y1 = (!S1) &   S0  & D;
assign Y2 =   S1  & (!S0) & D;
assign Y3 =   S1  &   S0  & D;
```

### DeMux1X4_2：if ... else（講義第 51 頁）
```verilog
always @(*) begin           // 講義：always @(D or S0 or S1)
    if ((S1 == 1'b0) & (S0 == 1'b0)) begin
        Y0 = D;  Y1 = 0;  Y2 = 0;  Y3 = 0;
    end
    else if ((S1 == 1'b0) & (S0 == 1'b1)) begin
        Y0 = 0;  Y1 = D;  Y2 = 0;  Y3 = 0;
    end
    else if ((S1 == 1'b1) & (S0 == 1'b0)) begin
        Y0 = 0;  Y1 = 0;  Y2 = D;  Y3 = 0;
    end
    else if ((S1 == 1'b1) & (S0 == 1'b1)) begin
        Y0 = 0;  Y1 = 0;  Y2 = 0;  Y3 = D;
    end
end
```
- `(S1 == 1'b0) & (S0 == 1'b0)`：兩個比較的結果都是 1 位元，用 `&` 連起來表示「且」（講義第 51 頁紅字「且」）。
  更常見的寫法是邏輯運算子 `&&`，在 1 位元的情況下兩者結果一樣。
- 每個分支都給了 4 個輸出值，但和 10 範例一樣**沒有最後的 else**，S1 / S0 不確定時輸出會保持舊值（latch）。
  其實這裡用 `case ({S1, S0})` 加 `default` 會更簡潔。

### 講義的模組名稱重複
講義第 51 頁的檔名是 `DeM1X4_2.V`，但模組名稱寫成 `DeMux1x4_1`，和第 50 頁的範例 1 **同名**。
兩個檔案一起編譯時，後編譯的會蓋掉先編譯的，testbench 就分不出來。所以這裡改名為 `DeMux1X4_2`。

## 3. 預期輸出

S1 S0 跑 00~11，每一組 D 依序給 1、0：

```
t=0   S1S0=00 D=1  ->  _1: Y3..Y0=0001   _2: Y3..Y0=0001     ← D 出現在 Y0
t=10  S1S0=00 D=0  ->  _1: Y3..Y0=0000   _2: Y3..Y0=0000
t=20  S1S0=01 D=1  ->  _1: Y3..Y0=0010   _2: Y3..Y0=0010     ← Y1
t=30  S1S0=01 D=0  ->  _1: Y3..Y0=0000   _2: Y3..Y0=0000
t=40  S1S0=10 D=1  ->  _1: Y3..Y0=0100   _2: Y3..Y0=0100     ← Y2
t=50  S1S0=10 D=0  ->  _1: Y3..Y0=0000   _2: Y3..Y0=0000
t=60  S1S0=11 D=1  ->  _1: Y3..Y0=1000   _2: Y3..Y0=1000     ← Y3
t=70  S1S0=11 D=0  ->  _1: Y3..Y0=0000   _2: Y3..Y0=0000
```

### 觀察重點
- S1 S0 是幾，D 就出現在 Y 的第幾條（講義第 50、51 頁方塊圖上的 00、01、10、11）。
- D = 1 時看起來和 2 對 4 解碼器一樣（one-hot）。其實**解多工器 = 把 D 當作致能的解碼器**。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 1 對 2ⁿ 解多工器 | n 條選擇線、2ⁿ 條輸出 |
| 布林方程式 | 每個輸出 = 選擇線的組合 AND D |
| 模組名稱 | 同一次編譯中不可重複 |
| 解多工器 vs 解碼器 | 解多工器 = D 當致能的解碼器 |
