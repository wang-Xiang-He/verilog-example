# 03_Decod_Fcn 範例說明：用 2 對 4 解碼器函數做 3 對 8 解碼器（範例練習 6-002）

## 1. 這個範例在做什麼？

3 對 8 解碼器可以用**兩個 2 對 4 解碼器**組成（講義第 10 頁方塊圖）：

- `Din[1:0]` 同時接到兩個解碼器
- `Din[2]` 當**致能**（ce, chip enable）：0 時下面那個動作，1 時上面那個動作

```
Din[1:0] ──┬──► decod4 ──► Y[3:0]     ce = ~Din[2]
           │
           └──► decod4 ──► Y[7:4]     ce =  Din[2]
```

| Din | Y |
|-----|---|
| 000 | 0000_0001 |
| 001 | 0000_0010 |
| 010 | 0000_0100 |
| 011 | 0000_1000 |
| 100 | 0001_0000 |
| … | … |
| 111 | 1000_0000 |

---

## 2. 檔案說明

### decod_fcn.v
```verilog
always @(*) begin
    Ytmp[7:4] = decod4(Din[1:0],  Din[2]);
    Ytmp[3:0] = decod4(Din[1:0], ~Din[2]);
end
assign Y = Ytmp;

function [3:0] decod4 (
    input [1:0] D,
    input       ce
);
    if (ce == 1'b1) begin
        case (D)
            2'b00   : decod4 = 4'b0001;
            2'b01   : decod4 = 4'b0010;
            2'b10   : decod4 = 4'b0100;
            2'b11   : decod4 = 4'b1000;
            default : decod4 = 4'b0000;
        endcase
    end
    else
        decod4 = 4'b0000;
endfunction
```
- 函數回傳 4 位元，直接指定給 `Ytmp` 的**部分選取** `[7:4]`、`[3:0]`。
- 引數可以是運算式：`~Din[2]` 先算好再傳進去。
- 函數本體只有一個 `if ... else` 敘述，所以可以不寫最外層的 `begin ... end`。
- 函數裡的 `if` 和 `case` 每條路徑都有給回傳值，才不會出現 x。
- 對照 week03 的 11_Decoder（用左移運算子做 3 對 8 解碼器）：同一個電路的另一種寫法。

### decod_fcn_tb.v（講義第 11 頁）
`Din` 每個時脈正緣加 1，跑完 000~111。講義沒寫結束條件，加上 `#170 $stop`。

## 3. 預期輸出

```
t=0    Din=000 (0)  ->  Y=00000001
t=10   Din=001 (1)  ->  Y=00000010
t=30   Din=010 (2)  ->  Y=00000100
t=50   Din=011 (3)  ->  Y=00001000
t=70   Din=100 (4)  ->  Y=00010000   ← Din[2] 變 1，換上半部動作
t=90   Din=101 (5)  ->  Y=00100000
t=110  Din=110 (6)  ->  Y=01000000
t=130  Din=111 (7)  ->  Y=10000000
t=150  Din=000 (0)  ->  Y=00000001
```

### 觀察重點
- 每次只有一個位元是 1（one-hot），位置就是 Din 的值。
- Din = 0~3 時高 4 位元全 0（上半部 ce = 0），Din = 4~7 時低 4 位元全 0。
- 和講義第 12 頁波形的 00000001、00000010、00000100 … 相同。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 用小模組組大模組 | 2 個 2 對 4 解碼器 → 3 對 8 解碼器 |
| 致能 ce | 最高位元決定哪一半動作 |
| 函數回傳向量 | `function [3:0] decod4` |
| 函數內可用 | `if`、`case`、`for` 等行為敘述 |
