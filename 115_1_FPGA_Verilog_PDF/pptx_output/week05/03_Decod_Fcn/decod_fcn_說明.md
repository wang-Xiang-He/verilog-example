# 03_Decod_Fcn 範例說明：用 2 對 4 解碼器函數做 3 對 8 解碼器（範例練習 6-002）

## 1. 先認識解碼器：「2 對 4」是什麼意思？

### 解碼器在做什麼
把一個**二進位數字**，轉成「**第幾條線亮**」。

「2 對 4」= **2 條輸入線、4 條輸出線**。
2 個位元能表示 4 種組合（00、01、10、11），所以需要 4 條輸出，每種組合各對應一條。
輸入是多少，就只有**那一條**輸出是 1，其他全是 0：

| 輸入 D（二進位） | 十進位 | 輸出 F3 F2 F1 F0 | 哪一條亮 |
|---|---|---|---|
| 00 | 0 | 0 0 0 **1** | F0 |
| 01 | 1 | 0 0 **1** 0 | F1 |
| 10 | 2 | 0 **1** 0 0 | F2 |
| 11 | 3 | **1** 0 0 0 | F3 |

```
           ┌─────────┐
  D[1] ───►│         │──► F0
           │  2 對 4  │──► F1
  D[0] ───►│ 解碼器   │──► F2
           │         │──► F3
           └─────────┘
```

可以想成一排房間的門鈴：你按的號碼是 2 位元的二進位數字，解碼器負責讓「那一間」的門鈴響，其他間都不響。
這種「同一時間只有一個位元是 1」的編碼叫做 **one-hot**。

### 命名規則：n 對 2ⁿ
輸入 n 條線有 2ⁿ 種組合，所以輸出是 2ⁿ 條：

| 名稱 | 輸入 | 輸出 |
|---|---|---|
| 2 對 4 | 2 位元 | 2² = 4 條 |
| 3 對 8 | 3 位元 | 2³ = 8 條 |
| 4 對 16 | 4 位元 | 2⁴ = 16 條 |

### 致能（ce, enable）
本範例的 2 對 4 解碼器多了一個**致能**輸入 `ce`，可以把它想成整個解碼器的總開關：
- `ce = 1`：正常解碼，照上面的表輸出
- `ce = 0`：整個關掉，4 條輸出**全部是 0**，不管 D 是多少

有了致能，才能把好幾個小解碼器拼成一個大的（見下一節）。

### 實際用在哪裡
最典型的是**選擇晶片或記憶體**。例如有 4 顆記憶體，用 2 個位址位元經過 2 對 4 解碼器，
就能保證每次只有一顆被選中，不會兩顆同時回應。

> 對照 week03 的 [11_Decoder](../../week03/11_Decoder/Decoder_說明.md)：同樣是 3 對 8 解碼器，那邊用左移運算子 `Out = 1'b1 << in` 一行寫完。

## 2. 這個範例在做什麼？

3 對 8 解碼器可以用**兩個 2 對 4 解碼器**組成（講義第 10 頁方塊圖）：

- `Din[1:0]` 同時接到兩個解碼器
- `Din[2]` 當**致能**（ce, chip enable）：0 時下面那個動作，1 時上面那個動作

```
Din[1:0] ──┬──► decod4 ──► Y[3:0]     ce = ~Din[2]
           │
           └──► decod4 ──► Y[7:4]     ce =  Din[2]
```

| Din | Y |
|-----|---|
| 000 | 0000_0001 |
| 001 | 0000_0010 |
| 010 | 0000_0100 |
| 011 | 0000_1000 |
| 100 | 0001_0000 |
| … | … |
| 111 | 1000_0000 |

### 實際走一次：Din = 110（十進位 6）
1. `Din[2] = 1` → 上面那個解碼器 `ce = 1`（開），下面那個 `ce = ~1 = 0`（關）
2. 兩個解碼器都收到 `Din[1:0] = 10`
3. 上面那個：`D = 10` → 輸出 `0100`，放到 `Y[7:4]`
4. 下面那個：關掉 → 輸出 `0000`，放到 `Y[3:0]`
5. 合起來 `Y = 0100_0000`，第 6 位是 1，剛好等於 Din 的值

## 3. 檔案說明

### decod_fcn.v
```verilog
always @(*) begin
    Ytmp[7:4] = decod4(Din[1:0],  Din[2]);
    Ytmp[3:0] = decod4(Din[1:0], ~Din[2]);
end
assign Y = Ytmp;

function [3:0] decod4 (
    input [1:0] D,
    input       ce
);
    if (ce == 1'b1) begin
        case (D)
            2'b00   : decod4 = 4'b0001;
            2'b01   : decod4 = 4'b0010;
            2'b10   : decod4 = 4'b0100;
            2'b11   : decod4 = 4'b1000;
            default : decod4 = 4'b0000;
        endcase
    end
    else
        decod4 = 4'b0000;
endfunction
```
- 函數回傳 4 位元，直接指定給 `Ytmp` 的**部分選取** `[7:4]`、`[3:0]`。
- 引數可以是運算式：`~Din[2]` 先算好再傳進去。
- 函數本體只有一個 `if ... else` 敘述，所以可以不寫最外層的 `begin ... end`。
- 函數裡的 `if` 和 `case` 每條路徑都有給回傳值，才不會出現 x。

### decod_fcn_tb.v（講義第 11 頁）
`Din` 每個時脈正緣加 1，跑完 000~111。講義沒寫結束條件，加上 `#170 $stop`。

## 4. 預期輸出

```
t=0    Din=000 (0)  ->  Y=00000001
t=10   Din=001 (1)  ->  Y=00000010
t=30   Din=010 (2)  ->  Y=00000100
t=50   Din=011 (3)  ->  Y=00001000
t=70   Din=100 (4)  ->  Y=00010000   ← Din[2] 變 1，換上半部動作
t=90   Din=101 (5)  ->  Y=00100000
t=110  Din=110 (6)  ->  Y=01000000
t=130  Din=111 (7)  ->  Y=10000000
t=150  Din=000 (0)  ->  Y=00000001
```

### 觀察重點
- 每次只有一個位元是 1（one-hot），位置就是 Din 的值。
- Din = 0~3 時高 4 位元全 0（上半部 ce = 0），Din = 4~7 時低 4 位元全 0。
- 和講義第 12 頁波形的 00000001、00000010、00000100 … 相同。

## 5. 重點整理

| 觀念 | 說明 |
|------|------|
| 用小模組組大模組 | 2 個 2 對 4 解碼器 → 3 對 8 解碼器 |
| 致能 ce | 最高位元決定哪一半動作 |
| 函數回傳向量 | `function [3:0] decod4` |
| 函數內可用 | `if`、`case`、`for` 等行為敘述 |
