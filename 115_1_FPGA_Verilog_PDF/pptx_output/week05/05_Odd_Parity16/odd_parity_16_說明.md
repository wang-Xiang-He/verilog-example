# 05_Odd_Parity16 範例說明：用 8 位元任務做 16 位元奇同位元產生器（範例練習 6-003）

## 1. 這個範例在做什麼？

和 02_Even_Parity16 結構相同，但有兩個不同：

1. 改成**奇同位**（odd parity）：資料 + 同位元，1 的總數是**奇數**。
2. 8 位元的部分改用**任務** `odd8`，不是函數。

```
Din[15:8] ──► odd8 ──► High ─┐
                             XNOR ──► Pout
Din[7:0]  ──► odd8 ──► Low  ─┘
```

> 講義第 18 頁的標題寫「完成 16 位元**偶**同位元產生器」，但第 19、20 頁的說明和程式都是 `odd_parity_16`（奇同位）。
> 本範例依程式碼，做的是**奇同位**。

### 為什麼最後是 XNOR？
- `High = ~^高位元組`、`Low = ~^低位元組`（各自的奇同位元）
- 16 位元奇同位元 = `~^Din` = `~(^高 ^ ^低)`
- `High ^ Low = (~^高) ^ (~^低) = ^高 ^ ^低`（兩個反相抵銷）→ 所以還要再反相一次 → **XNOR**

## 2. 檔案說明

### odd_parity_16.v
```verilog
always @(*) begin
    High_byte = Din[15:8];
    Low_byte  = Din[7:0];
    odd8(High_byte, High);
    odd8(Low_byte,  Low);
    Pout = High ~^ Low;
end

task odd8 (
    input  [7:0] I,
    output       P
);
    begin
        P = ~^I;
    end
endtask
```

### 和函數版本逐行比較

| | 02 函數 `even8` | 05 任務 `odd8` |
|---|---|---|
| 宣告 | `function even8 (input [7:0] I);` | `task odd8 (input [7:0] I, output P);` |
| 傳回結果 | `even8 = ^I;`（指定給函數名稱） | `P = ~^I;`（指定給 output 引數） |
| 呼叫 | `High = even8(High_byte);` | `odd8(High_byte, High);` |

- 任務**沒有回傳值**，不能寫 `High = odd8(...)`；要多一個 output 引數把結果帶出來。
- `~^`：寫在一個運算元**前面**是縮減 XNOR（`~^I`），寫在兩個運算元**中間**是逐位元 XNOR（`High ~^ Low`）。
- 講義把任務的輸出也取名 `odd8`（和任務同名），ModelSim 可以編譯，但容易和函數的「同名回傳變數」搞混，這裡改名為 `P`。

## 3. 預期輸出

```
t=0   Din=0000 (0000000000000000)  ->  High=1 Low=1  Pout=1   ← 0 個 1，補 1 變成奇數
t=10  Din=0a0a (0000101000001010)  ->  High=1 Low=1  Pout=1
t=20  Din=24f5 (0010010011110101)  ->  High=1 Low=1  Pout=1
t=30  Din=ad12 (1010110100010010)  ->  High=0 Low=1  Pout=0   ← 已經有 7 個 1
t=40  Din=8976 (1000100101110110)  ->  High=0 Low=0  Pout=1
t=50  Din=4536 (0100010100110110)  ->  High=0 Low=1  Pout=0
t=60  Din=a123 (1010000100100011)  ->  High=0 Low=0  Pout=1
```

### 觀察重點
- 和 02_Even_Parity16 用同樣的 7 筆資料，**每一筆的 High、Low、Pout 都剛好相反**。
- Din 有偶數個 1 時 Pout = 1，補上之後總數變成奇數。
- 全 0 的資料在奇同位下同位元是 1：這是奇同位的優點，可以分辨「真的全 0」和「線路斷了」。

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| 奇同位元 | `~^資料` |
| 任務傳回結果 | 用 output 引數 |
| 任務呼叫 | 自成一行敘述，不能放在運算式裡 |
| `~^` | 縮減 XNOR / 逐位元 XNOR |
