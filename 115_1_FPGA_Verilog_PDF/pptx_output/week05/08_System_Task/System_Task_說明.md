# 08_System_Task 範例說明：系統函數與任務

## 1. 這個範例在做什麼？

名稱以 **`$`** 開頭的是模擬器**內建**的系統任務 / 系統函數（講義第 35 頁）。
它們只在模擬時有作用，**不會合成成電路**，所以幾乎都寫在 testbench 裡。

| 名稱 | 種類 | 作用 |
|------|------|------|
| `$display(...)` | 系統任務 | 顯示一行文字，**自動換行** |
| `$write(...)` | 系統任務 | 顯示文字，**不換行**（游標留在同一行） |
| `$monitor(...)` | 系統任務 | 清單中的訊號一有變化就自動顯示 |
| `$time` | 系統函數 | 回傳目前的模擬時間 |
| `$random` | 系統函數 | 回傳 32 位元亂數（07_Comp16_T_TF 有用到） |
| `$stop` | 系統任務 | **暫停**模擬，可以繼續看波形 |
| `$finish` | 系統任務 | **結束**模擬（跳離執行中的模擬程式） |

系統「任務」自成一行；系統「函數」有回傳值，用在運算式或引數裡 — 和自己寫的 task / function 規則一樣。
並不是所有系統函數與任務每一套模擬器都支援，以 ModelSim 的說明文件為準。

## 2. 檔案說明

### System_Task_tb.v
只有 testbench，沒有電路本體。

```verilog
$display("data = %h (hex), %0d (dec), %o (oct)", data, data, data);
```
格式字串的寫法（和 C 語言的 printf 類似）：

| 格式 | 意義 |
|------|------|
| `%b` | 二進位 |
| `%h` | 十六進位 |
| `%d` / `%0d` | 十進位（`%0d` 不補空白） |
| `%o` | 八進位 |
| `%s` | 字串 |
| `\n` | 換行 |

```verilog
for (i = 7; i >= 0; i = i - 1)
    $write("%b ", data[i]);     // 8 次都印在同一行
$write("\n");                   // $write 要自己加換行
```

檔案裡還有一個自己寫的函數 `count_ones`，直接當成 `$display` 的引數：
```verilog
$display("count_ones(data) = %0d", count_ones(data));
```

### `$stop` 與 `$finish`
講義用 `$finish`。在 ModelSim 圖形介面執行到 `$finish` 會跳出「是否要關閉 ModelSim」的詢問視窗，
所以所有範例都改用 `$stop`：模擬暫停，Transcript 和波形都保留。
（在 EDA Playground 上則要用 `$finish`，否則模擬不會結束。）

## 3. 預期輸出

```
--- (1) $display ---
data = 10100101
data = a5 (hex), 165 (dec), 245 (oct)
count_ones(data) = 4
--- (2) $write ---
1 0 1 0 0 1 0 1
--- (3) $time ---
time = 0
time = 25
--- (4) $stop ---
```

### 觀察重點
- `$display` 每呼叫一次就是一行。
- `$write` 被 for 迴圈呼叫 8 次，8 個位元印在**同一行**，最後補一個 `\n` 才換行。
- 兩次 `$time` 之間有 `#25`，所以時間從 0 變成 25。

---

## 4. 重點整理

| 觀念 | 說明 |
|------|------|
| `$` 開頭 | 模擬器內建，不能合成 |
| `$display` vs `$write` | 差在會不會自動換行 |
| `$time` | 目前模擬時間 |
| `$stop` vs `$finish` | 暫停 vs 結束 |
| 格式字串 | `%b` `%h` `%d` `%o` `%s` |
